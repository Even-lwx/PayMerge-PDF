# 发票合并工具 v5.0

> 原创作者：ZhangStudyLife
> 当前版本：v5.0 智能数据提取稳定版

智能发票合并工具，支持PDF发票与购买/支付记录图片合并，自动提取发票信息并智能命名。

## ✨ 核心特性

### 🔍 智能数据提取
- **自动识别发票信息**：发票号码、开票日期、金额、销售方名称
- **多格式支持**：适配多种发票格式和日期格式
- **智能文件命名**：`日期_金额_发票号后4位_已合并.pdf`
- **CSV汇总记录**：自动生成 `发票汇总记录.csv` 持续记录所有发票信息

### 🎨 智能布局系统
- **自动旋转优化**：测试8种旋转组合（2³种可能），选择最优方案
- **双重布局算法**：
  - 水平布局：发票上，记录下（根据比例分配）
  - 垂直布局：发票左，记录右（纵向排列）
- **空间最大化**：自动选择空间利用率最高的布局方案
- **A4标准页面**：纵向，15mm边距，300 DPI高质量渲染

### 🖱️ 友好交互界面
- **拖放操作**：支持文件拖拽（需 tkinterdnd2）
- **实时预览**：数据提取结果和文件命名预览
- **后台处理**：多线程处理，界面流畅不卡顿
- **容错设计**：数据提取失败不影响合并功能

## 🚀 快速开始

### 安装依赖

```bash
# 运行时依赖
pip install -r requirements.txt

# 打包依赖（仅需打包时）
pip install -r requirements-build.txt
```

### 运行程序

```bash
# 直接运行主程序
python invoice_merger_v5_stable.py
```

### 使用步骤

1. **启动程序**：运行 `invoice_merger_v5_stable.py`
2. **拖放文件**：将1个PDF发票 + 2张图片（购买/支付记录）拖到界面
3. **自动提取**：程序自动提取发票数据并显示
4. **预览命名**：查看智能生成的文件名
5. **智能合并**：点击【智能合并】按钮
6. **查看结果**：获得智能命名的PDF + CSV汇总记录

## 📋 文件命名规则

### 输入文件匹配
- PDF发票：任意名称，如 `1开发板19.9.pdf`
- 购买记录：`[前缀]购买记录.(jpg|png)`
- 支付记录：`[前缀]支付记录.(jpg|png)`

### 输出文件命名
**格式**：`日期_金额_发票号后4位_已合并.pdf`

**示例**：
- `20250926_199.00元_#5678_已合并.pdf`
- `20251231_355.50元_#5432_已合并.pdf`

## 📊 CSV汇总记录

自动生成 `发票汇总记录.csv`，包含以下字段：
- 发票号码
- 开票日期
- 金额
- 销售方名称
- 原文件名
- 合并文件名
- 处理时间

文件使用 UTF-8 BOM 编码，可直接用 Excel 打开。

## 🔧 技术细节

### 核心依赖
- **PyPDF2** (3.0.1): PDF基础操作
- **Pillow** (10.4.0): 图片处理和合成
- **pypdfium2** (4.30.0): PDF文本提取和渲染
- **tkinterdnd2**: 拖放功能（可选，无此库时回退到按钮选择）

### 智能布局算法

位置: `merge_invoices_simple.py:71-154`

1. 测试所有旋转组合（2³=8种）
2. 对每种组合评估两种布局：
   - 水平布局：发票上，记录下
   - 垂直布局：发票左，记录右
3. 计算每种方案的缩放因子总和（空间利用率）
4. 选择得分最高的方案

### 数据提取流程

位置: `invoice_merger_v5_stable.py:405-455`

1. 使用 pypdfium2 渲染PDF前3页为文本
2. 多模式正则表达式匹配：
   - 发票号码：`发票号码[：:\s]*(\d{8,20})`
   - 开票日期：`开票日期[：:\s]*(\d{4}[-年]\d{1,2}[-月]\d{1,2}日?)`
   - 金额：`价税合计[：:\s]*¥?(\d+\.?\d*)`
   - 销售方：`销售方[：:\s]*([^\n\r]+?)(?:\s|纳税人)`
3. 日期标准化：统一转换为 `YYYYMMDD` 格式
4. 容错处理：提取失败使用"未识别"标记

## ⚠️ 注意事项

1. **不修改源文件**：程序使用临时文件，不会修改原始PDF和图片
2. **CSV持续累积**：汇总文件会持续记录，不会覆盖
3. **容错设计**：即使数据提取失败，合并功能仍可正常使用
4. **线程安全**：数据提取在后台线程，避免界面冻结
5. **中文路径**：支持中文路径，但建议使用英文路径以避免潜在问题
