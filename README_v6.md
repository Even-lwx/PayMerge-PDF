# 发票合并工具 v6.0 - 多页 PDF 支持版

## 版本信息

- **版本号**: v6.0
- **更新日期**: 2026 年 1 月 13 日
- **主要更新**: 多页 PDF 支持、配置持久化、简化操作流程

## 新增功能

### 1. 用户配置持久化

- 首次运行时需要输入使用者姓名和组别
- 配置信息保存在软件根目录的 `config.json` 文件中
- 支持随时修改配置信息（点击主界面的"?? 修改配置"按钮）
- 后续打开软件自动读取已保存的配置

### 2. 多页 PDF 完整支持

- **v5 版本限制**: 仅能处理单页 PDF，多页 PDF 只读取第一页
- **v6 版本升级**: 支持任意页数的 PDF 发票（常见 2-3 页）
- 发票的每一页均独立占据输出文档中 A4 纸大小的 1/2 区域
- 按发票原页码顺序排列

### 3. 智能分页排版算法

#### 单页发票布局

```
┌─────────────────────────────┐
│                             │
│      发票第1页 (1/2)        │
│                             │
├──────────────┬──────────────┤
│  购买记录    │  支付记录    │
│   (1/4)      │   (1/4)      │
└──────────────┴──────────────┘
```

#### 多页发票布局（以 3 页为例）

**第一页 A4:**

```
┌─────────────────────────────┐
│      发票第1页 (1/2)        │
├─────────────────────────────┤
│      发票第2页 (1/2)        │
└─────────────────────────────┘
```

**第二页 A4:**

```
┌─────────────────────────────┐
│      发票第3页 (1/2)        │
├──────────────┬──────────────┤
│  购买记录    │  支付记录    │
│   (1/4)      │   (1/4)      │
└──────────────┴──────────────┘
```

### 4. 新的文件命名规则

- **v5 格式**: `日期_金额_发票号后4位_已合并.pdf`
- **v6 格式**: `姓名_组别_金额_发票后四位.pdf`
- 示例: `张三_销售组_199.00_5678.pdf`

### 5. 简化操作流程

- **v5 版本**: 需要分别点击"? 提取数据"和"? 智能合并"两个按钮
- **v6 版本**: 只需点击"? 一键输出"按钮
- 自动完成：数据提取 → PDF 合并 → 文件命名 → 保存输出
- 输出文件自动保存到软件根目录（无需选择保存位置）

## 使用说明

### 首次运行

1. 运行程序后会弹出配置对话框
2. 输入您的姓名和组别
3. 点击"确定"保存配置
4. 配置信息会保存在 `config.json` 文件中

### 日常使用

1. **选择文件**:

   - 拖放或点击"? 选择文件"按钮
   - 选择 1 个 PDF 发票（支持多页）
   - 选择 2 张图片（按顺序：购买记录、支付记录）

2. **一键输出**:

   - 确认文件选择无误
   - 点击"? 一键输出"按钮
   - 程序自动完成所有处理

3. **查看结果**:
   - 合并后的 PDF 自动保存到软件根目录
   - 文件名格式：`姓名_组别_金额_发票后四位.pdf`
   - 同时记录到 CSV 汇总文件

### 修改配置

- 点击主界面的"?? 修改配置"按钮
- 修改姓名或组别
- 新配置立即生效，影响后续生成的文件名

## 文件说明

### 主要文件

- `invoice_merger_v6.py` - 主程序（GUI + 业务逻辑）
- `merge_invoices_v6.py` - PDF 合并引擎（支持多页）
- `build_v6_exe.py` - 打包脚本
- `config.json` - 用户配置文件（首次运行后生成）
- `发票汇总记录.csv` - CSV 汇总文件

## 技术特性

### PDF 处理

- 使用 `pypdfium2` 高性能 PDF 库
- 支持任意页数 PDF 渲染
- 300 DPI 高质量输出

### 图片处理

- 使用 `Pillow (PIL)` 图像处理库
- 自动等比缩放，保持图片清晰度
- 智能居中对齐

### 排版算法

- A4 纸张标准尺寸 (210mm × 297mm)
- 15mm 边距设置
- 智能分页：发票页配对 + 最后一页加截图

### 数据提取

- 从发票第一页提取关键信息
- 正则表达式多策略匹配
- 支持发票号码、金额、日期、销售方

## 注意事项

1. **图片顺序**: 按文件名字母排序，第一张作为购买记录，第二张作为支付记录
2. **PDF 页数**: 建议 2-3 页，过多页面会导致输出文档较长
3. **配置文件**: 不要手动删除 `config.json`，否则需要重新配置
4. **输出目录**: 文件保存在 exe 所在目录或 py 脚本所在目录

## 常见问题

### Q: 提示"未检测到 pypdfium2 库"？

A: 运行 `pip install pypdfium2` 安装 PDF 处理库

### Q: 拖放功能不可用？

A: 安装 `tkinterdnd2` 库，或使用"选择文件"按钮

### Q: 如何修改姓名和组别？

A: 点击主界面的"?? 修改配置"按钮

### Q: 多页 PDF 如何排版？

A: 前 N-1 页每页放 2 个发票页，最后一页放剩余发票页+两张截图

### Q: 输出文件保存在哪里？

A: 自动保存在软件根目录（exe 所在文件夹）
